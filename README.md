# Analisador Léxico

Projeto acadêmico individual desenvolvido na disciplina de Compiladores, com o objetivo de implementar um analisador léxico capaz de identificar e classificar elementos de um código-fonte em tokens.

## Conceitos aplicados
- Análise léxica e processamento de código-fonte.
- Reconhecimento e classificação de tokens.
- Identificação de palavras reservadas e identificadores.
- Utilização de expressões regulares.
- Fundamentos de autômatos finitos.

## Objetivo
Compreender e aplicar os conceitos fundamentais da primeira etapa de um compilador, explorando técnicas de reconhecimento de padrões e identificação de unidades léxicas.
